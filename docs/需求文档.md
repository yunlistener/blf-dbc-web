# BLF/DBC CAN 总线分析平台 — 需求文档

> 版本:v84(2026-08-23)
> 仓库:yunlistener/blf-dbc-web(私有)
> 维护者:用户 + Hermes Agent(协同开发)

---

## 1. 项目概述

### 1.1 目标

基于网页的 CAN/CAN FD 总线日志(BLF)分析平台:**上传 BLF 日志 + DBC 数据库 → 浏览器中浏览报文/信号、绘制 CANoe 风格示波器曲线、统计分析、导出**。部署于树莓派(ARM64),局域网内浏览器访问,数据不出内网。

### 1.2 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| BLF 解析 | python-can(BLFReader) | 流式逐帧解析,v1/v2/v3 |
| DBC 解析 | cantools | 事实标准,值表/多路复用支持 |
| Web 后端 | FastAPI + Uvicorn | 异步、Swagger 文档、内存 <100MB |
| 前端 | 原生 JS + uPlot(本地化 vendor/) | 百万点级流畅,min/max 保形降采样保留尖峰 |
| 部署 | systemd 常驻 + Uvicorn 直接服务 | 免 Docker,免编译(ARM64 全 wheel) |

### 1.3 里程碑状态

| 阶段 | 内容 | 状态 |
|---|---|---|
| M1 | 后端骨架:上传、DBC 解析 API、BLF 统计/解码 API | ✅ 完成 |
| M2 | CANoe 风格界面:报文树、多示波器、Trace、统计、导出 | ✅ 完成 |
| M3 | 树莓派 systemd 部署 | 🔶 首次部署完成,RPi 宕机待重装 |

## 2. 功能需求(已实现)

### 2.1 文件管理

- 上传 `.blf` / `.dbc` 文件(multipart);文件列表、删除
- 配置持久化(`data/config.json`):默认 BLF/DBC 文件、每通道 DBC 映射

### 2.2 DBC 解析(中文乱码已根治)

- 报文列表:ID(hex)、报文名、长度、信号列表、**发送 ECU 列表(senders)**
- 信号详情:起始位/位长/字节序/缩放/偏移/单位/**值表 choices**/min-max/**中文说明 comment**
- **编码自动检测**:UTF-8 → GBK → GB18030 strict 校验回退,按检测编码加载 + `lru_cache` 缓存
  - 真实 EEA DBC 为 **GBK 编码**,中文注释/信号说明正常显示(提交 `6f6c255`)

### 2.3 BLF 解析与性能

- **帧索引缓存**(`blf_cache.py`):首次全扫建帧索引 + LRU 4 文件/200 万帧 + mtime/size 校验
  - decode/frames/export 统一走缓存,**27 倍提速**(0.56s → 0.02s)
- 流式解析,内存预算 ~1GB;`max_points=200000` 前端降采样上限
- 无数据报文三层处理:decode 空数据返回 200+empty;前端选中容错自动回滚;信号树灰标+删除线

### 2.4 信号选择与示波器(核心)

**布局(CANoe 式)**:
- 左侧信号树(1/3 宽,搜索/排序)→ 已选信号列表(80~320px 可拖)→ 示波器区(上下排列,横贯全宽,固定高度,纵向滚动)
- **多示波器窗口**:每信号默认一个示波器;`+ / −` 按钮增删空示波器;**添加信号优先复用空示波器,无空才新建**
- 每个示波器标题栏:示波器号 + `+ 信号` 按钮 + 信号列表(色点+名称+**✕ 删除**)

**信号添加/分配**:
- 信号树点选信号 → 添加/删除(复用空示波器);信号树仅浏览
- 示波器 `+ 信号` 模态:**只列已选信号列表里的信号**(免 API 复制到目标示波器),标注"已在示波器 N"
- **同一信号可同时在多个示波器显示**(去重为 四元组 frame_id+signal+channel+plotId)
- 信号上限 **64 个**;20 色调色板循环

**坐标轴与时间同步**:
- **同窗信号共享一个 y 轴**:y 范围自动聚合窗口内全部信号值域 + 15% padding,信号移入移出时重算
- **y 范围对齐刻度 step 倍数(向下取整)**:负值信号(如加速度 -0.03g)的负数刻度可见
- 每个窗口底部有自己的**时间轴刻度**(时间同步后上下刻度对齐);滚轮缩放/框选放大/重置全窗口广播同步
- 恒值信号(全 0)扩开一格显示,水平线可见

**曲线渲染**:
- 普通信号:连续折线(宽度 2)
- **值表信号(choices)**:linear 折线 + **前向填充**(状态保持到下一采样,等效阶梯)
  - ⚠️ 曾用 `uPlot.paths.stepped` 渲染失败(依赖 scale.dir/ori,未配置→NaN→空路径),已改 linear+前向填充(`c841381`/`8148e6a`)

**交互**:
- 光标跟随 tooltip:时间 + 各信号值(名称(值)格式 + 单位)
- 框选放大、双击/重置缩放按钮
- **双点测量**:点击设黄色锚点,移动光标 tooltip 显示 Δt 与频率
- **抖动峰值标记**:信号统计 tab 计算后,示波器时间轴顶部画信号色小三角(配置抽屉可开关)
- 示波器高度三档把手:全页 / 2/3 / 收起

### 2.5 底部标签页

**Trace 帧浏览**:
- 按报文+通道显示帧:时间/ID/报文/DLC/FD 标记/**CH 列**/数据 hex
- 搜索(值匹配,支持表达式)、**缩放区间过滤**(读示波器当前缩放范围)、清除

**ID 统计**:每 ID 帧数/频率/时间范围;顶部总线负载率条(CAN/CAN FD 位时近似)

**信号统计**:
- 每信号:点数/min/max/mean/std/最后值(全部带单位)/**超范围检测**(对比 DBC min/max 标红)
- 值表信号:状态分布
- **周期抖动**:期望/实测周期/峰峰抖动/丢帧数,抖动行显示峰值时间点
- tab 打开状态下增删信号自动刷新

### 2.6 导出

- **CSV 区间导出**:导出按钮自动带当前缩放区间(start/end 参数),只导所见范围

### 2.7 配置抽屉

- 默认文件选择、通道 DBC 映射(保存到后端 config)
- **标记抖动峰值**开关(localStorage,即时生效)

### 2.8 持久化(刷新恢复)

- 已选信号(含示波器分配 plotId)保存到 localStorage,刷新后自动恢复
- 区分三态:首次使用(无记录)→ 自动选默认;有记录 → 恢复;已清空(空记录)→ 保持空
- **清空按钮**:一键清空所有信号+空示波器
- beforeunload 兜底保存

### 2.9 版本号

- 页头绿色徽标,自动从 `app.js?v=N` 读取;前端改动必须 bump `?v=N`(Edge 缓存顽固)

## 3. API 清单

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 健康检查 |
| GET | `/api/files` | 文件列表(blf/dbc) |
| POST | `/api/files/upload` | 上传文件 |
| DELETE | `/api/files/{name}` | 删除文件 |
| GET | `/api/dbc/{dbc}/messages` | 报文列表(含 senders) |
| GET | `/api/dbc/{dbc}/messages/{frame_id}` | 报文详情(含信号 comment/choices) |
| GET | `/api/blf/{blf}/stats` | 统计:by_id/channels/开始结束时间 |
| GET | `/api/blf/{blf}/decode` | 信号解码(支持 max_points 降采样) |
| GET | `/api/blf/{blf}/frames` | 帧数据(区间/搜索/分页) |
| GET | `/api/blf/{blf}/export` | CSV 导出(start/end 区间) |
| GET | `/api/blf/{blf}/signal-stats` | 信号统计(含超范围/值表分布) |
| GET | `/api/blf/{blf}/cycle-stats` | 周期统计(期望/实测/抖动/丢帧/峰值时间) |
| GET | `/api/blf/{blf}/bus-load` | 总线负载率 |
| GET/PUT | `/api/config` | 配置读写 |

## 5. 已踩坑与决策记录(重要)

### 5.1 uPlot 1.6 系列坑(源码级确认)

| 坑 | 表现 | 修复 |
|---|---|---|
| `range` 回调只在此 scale 无数据聚合时调用 | y 范围错误(0~247 显示 189~191) | setData 后显式算 y 范围并 setScale |
| series 配置创建时固定,setData 不能加列 | 同窗多信号时新信号曲线消失 | 信号数变化时销毁重建 uPlot |
| 后创建窗口 x scale 不自动计算 | x 范围 undefined,时间轴不画 | 显式 setScale x(数据范围或同步范围) |
| 未指定 scale 的轴按 side 猜测分配 | x 轴被猜成 y scale,刻度错位 | 所有轴显式 `scale:"x"/"y"` |
| side 枚举 0=上/1=右/2=下/3=左(与习惯相反) | y 轴画顶部、时间轴竖排右侧 | 按真实枚举配置 side |
| 刻度从 min 向上取整到 step 倍数 | 负值信号无负刻度 | y 范围对齐 step 倍数向下取整 |
| `uPlot.paths.stepped` 依赖 scale.dir/ori | 值表信号空路径不渲染 | 改 linear 折线 + 前向填充 |
| 多余预创建 y scale 自动生成空右轴 | 窗口右侧出现无意义刻度 | 多余轴显式 `show:false` |

### 5.2 后端

- cantools 对 GBK 字节不抛错只产乱码 → 必须主动编码检测(strict 校验)
- BLF 双通道:37 个重叠 ID 跨通道,必须按通道配置 DBC 解码
- 值表信号 decode 返回 dict(`{name, value}`),前端 per 构建提取 `.value`

### 5.3 部署/运维

- 前端资源改动必须 bump `?v=N`(Edge 缓存顽固,no-cache 不够)
- 树莓派首次部署完成,宕机待重装;部署流程见 `docs/部署运维.md`
