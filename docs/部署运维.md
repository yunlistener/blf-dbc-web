# 部署与运维

树莓派(Raspberry Pi 5,Debian 13 trixie aarch64)部署记录。

## 服务信息

| 项目 | 值 |
|---|---|
| 地址 | `http://10.10.0.142:8000/`(局域网) |
| 项目目录 | `/home/ling/blf-dbc-web`(uv 虚拟环境 `.venv` 在项目根) |
| 服务名 | `blf-dbc-web.service`(systemd,开机自启) |
| 启动命令 | `.venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000`(必须在 `backend/` 目录) |

## systemd 服务文件

`/etc/systemd/system/blf-dbc-web.service`:

```ini
[Unit]
Description=BLF/DBC Web CAN Analyzer (FastAPI + uPlot)
After=network.target

[Service]
Type=simple
User=ling
WorkingDirectory=/home/ling/blf-dbc-web/backend
ExecStart=/home/ling/blf-dbc-web/.venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

## 常用命令

```bash
sudo systemctl status blf-dbc-web      # 状态
sudo systemctl restart blf-dbc-web     # 重启
sudo systemctl stop blf-dbc-web        # 停止
sudo journalctl -u blf-dbc-web -f      # 查看日志
```

## 更新部署流程

```bash
# 1. 开发机(本机)同步代码到树莓派
rsync -az --delete --exclude .git --exclude .venv --exclude __pycache__ \
  --exclude .DS_Store --exclude '*.pyc' \
  ./ ling@10.10.0.142:/home/ling/blf-dbc-web/

# 2. 树莓派重启服务(前端静态文件无需重启,后端代码改动才需要)
sudo systemctl restart blf-dbc-web

# 3. 验证
curl http://10.10.0.142:8000/api/health
```

> 注意:rsync 的 `--exclude .venv` 必须保留,否则 `--delete` 会误删树莓派上的虚拟环境。

## 环境备忘

- apt / pip / uv 均已配清华镜像(`/etc/apt/sources.list.d/*.sources`、`~/.config/pip/pip.conf`、`~/.config/uv/uv.toml`)
- uv 0.12.5 在 `~/.local/bin`(GitHub 在该网络被墙,uv 从清华 PyPI 镜像安装)
- `rpi5.local` mDNS 不稳定,一律用 IP `10.10.0.142`

## 建议:固定 IP

当前 IP 由 DHCP 分配,可能变化。建议在**路由器后台**将该主机加入 DHCP 地址保留(IP-MAC 绑定),或改为静态 IP。树莓派 MAC 可在 `ip link` 查询。
